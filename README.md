# 拾藏资源库

轻量资源发布站。TypeScript + Hono + Cloudflare Workers / D1 / R2。第一版只开放夸克网盘，保留多网盘链接结构。

## 本地体验

需要 Node.js 22 或更高版本。

```sh
npm install
npm run db:init
npm run db:seed
npm run dev
```

- 前台：http://127.0.0.1:8787
- 后台：http://127.0.0.1:8787/admin
- 本地预览仅监听回环地址，并以明确的 `local` 环境免登录。不要将本地预览端口公开。
- 数据保存在项目 `.wrangler/state`，重启保留；本地演示数据不会自动写入生产数据库。
- `db:seed` 只用于本地演示，所有条目明确标记，不包含真实网盘地址。后台可一键清空演示资料。

## 已实现

- 服务端 HTML 首页、搜索、分类页、资源详情、相关资源、帮助页。
- 资源草稿、预览、发布、下架、精选、编辑、删除。
- 图片上传到 R2，支持 JPEG / PNG / WebP，大小限制与文件头检查。
- 单资源多个网盘入口、提取码复制、链接禁用与统一跳转。
- 分类创建与删除，网站名称及联系邮箱设置。
- 反馈提交、频率限制、管理员处理。
- 按北京时间统计最近 30 天网盘点击，区分 `?from=wechat` 等渠道。
- CSV 校验预览、重复检查、确认后原子批量导入为草稿（每次 15 条以内）。
- JSON 数据导出，生产 D1 和 R2 备份方式见部署文档。
- Cloudflare Access 后台权限验证、同源写入检查、安全响应头、正文转义。

## 验证

```sh
npm run check
npm run build
# 保持 npm run dev 运行，在另一个终端执行真实本地接口测试：
npm test
```

`npm test` 会创建并清理带随机标识的测试资料，不会删除演示或用户资料。统计与反馈测试会产生临时测试数据并随测试资源一起清理。完整生产身份边界测试可启动 `npx wrangler dev --local --ip 127.0.0.1 --port 8788`，再执行 `TEST_PRODUCTION_ORIGIN=http://127.0.0.1:8788 npm test`。

## 目录

- `src/index.ts`：公开页面、后台和数据接口。
- `src/views.ts`：HTML 页面模板及安全文本渲染。
- `src/security.ts`：管理员身份验证、写入来源验证、网盘域名配置。
- `public/`：本地静态样式、脚本和图标，不依赖第三方字体或脚本 CDN。
- `migrations/`：版本化数据库结构。
- `scripts/seed.sql`：独立的本地演示数据。
- `docs/DEPLOY.md`：用户自有 Cloudflare 账号部署与备份。

## 扩展边界

- 新网盘：在 `src/security.ts` 的 catalog 中核对域名并加入 `enabledProviderIds`，然后验证分享入口。数据库不需要改结构。
- 第一版没有自动转存、登录网盘或抓取资源功能，也不需要网盘 Cookie。
- 暂不提供会员收费、论坛、专题合集、AI 自动写文、精确 UV 或网盘佣金对账。
- 为保证草稿与下架立即生效，动态 HTML 与接口使用 `no-store`；图片长缓存，CSS/JS 由静态资源服务。未来按真实访问数据引入公开页面缓存及失效策略。
- 初期搜索使用参数化 LIKE 查询标题、简介与标签；分类和公开列表有索引。资源达到较大规模时需测量查询行数并升级中文检索索引。
- `daily_clicks` 记录入口请求，不是去重人数；机器人、预取和重复点击可能影响数字。
- 当前 JSON 导出供数据审阅与迁移，数据库恢复使用 D1 SQL 导出；图片单独备份。

## 当前搜索版（2026-09-14）

首页已改为纯搜索。本站资源优先，零匹配时通过同项目内的 PanSou 查询网络夸克资源；搜索设置支持频道和插件选择。已新增求资源表单与后台处理列表。

`npm run dev` 现在会同时编译并启动 PanSou 与网站，需要 Go 1.24.9+（当前机器使用项目内 `.tools/go`）。Cloudflare 部署加入同项目的 Containers，额外计费，不再是纯 Worker 部署。详见 [PanSou 接入说明](docs/PANSOU.md)。
